# Plan your Trip!——旅行路線模組系統

本專案以簡化的捷運路網為情境建立旅行路線模組系統。
使用者可查看路線與站點、輸入起訖站查詢經過站數最少的路徑，並新增、刪除或修改個人行程中的站點。

## 主要功能

| 功能 | 說明 |
| --- | --- |
| 瀏覽所有路線 | 列出示範路網中的路線與各路線站點。 |
| 查詢指定路線 | 輸入路線名稱，依站點順序顯示該路線。 |
| 查詢建議路徑 | 輸入出發站與目的站，以 DFS 找出可行路徑，並顯示經過站數最少的路徑；若有並列結果，一併列出。 |
| 查看旅行計畫 | 顯示目前記錄的行程站點。 |
| 編修旅行計畫 | 新增、刪除或修改行程站點，操作後顯示更新的行程。 |

主選單另提供離開系統的選項。

## 資料結構與實作

- 圖形與 DFS：以站點 ID 和相鄰站點建立路網，遍歷起訖站之間不重複站點的可行路徑，再比較路徑中的站點數。
- AVL Tree：以路線組織站點，透過中序遍歷依順序輸出指定路線的站點。
- 鏈結串列：保存旅行計畫中的站點，支援新增、刪除、修改與依序顯示。

## 程式檔案

| 檔案名稱 | 內容 |
| --- | --- |
| `main.py` | 提供命令列主選單，串接路線查詢、路徑查詢及旅行計畫操作。 |
| `name.py` | 儲存站名與 ID、站點相鄰關係，以及各路線包含的站點。 |
| `list_map.py` | 建立路線與站點結構，實作 AVL Tree、路線搜尋及站點顯示。 |
| `shortest_path.py` | 將站名轉為 ID，以 DFS 搜尋可行路徑並選出經過站數最少的結果。 |
| `trip_revise.py` | 以鏈結串列實作旅行計畫的新增、刪除、修改與顯示。 |

## 執行方式

在包含上述程式檔案的資料夾中執行：

```bash
python3 main.py
```

依命令列選單輸入選項，並在提示時輸入路線、站名或行程站點。
